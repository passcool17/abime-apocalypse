# Abîme de l'Apocalypse

Jeu de rôle tactique sombre, au tour par tour, à la manière de *Darkest Dungeon* — jouable directement dans le navigateur.

**Jouer : https://passcool17.github.io/abime-apocalypse/**

Quatre héros — Enoch, Elior, Christ et Thoth — affrontent les démons et les créatures de l'Apocalypse
dans trois donjons, puis reviennent au hameau pour se soigner avec l'or gagné.

- Phaser 3 (CDN), HTML/JS sans étape de compilation.
- Souris ou tactile (format paysage recommandé sur téléphone).
- Sauvegarde automatique dans le navigateur (localStorage).
- Fiche de conception et état du jeu : [GAME.md](GAME.md).
- Test de logique : `node test/smoke.js`.

Portraits des héros : art original de Pascal. Ennemis : dessins vectoriels provisoires.
